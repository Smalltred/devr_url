# 宝塔部署说明（Node.js 版）

本包是完整部署包：编译好的前端 + Node 后端源码 + 依赖清单。**不再需要 PHP / Composer / Redis**；
数据库使用 SQLite 单文件，外链巡检在 Node 进程内定时执行，无需额外配置计划任务。

## 环境要求

- Node.js **24+**（必需：使用内置 `node:sqlite`，无需编译原生模块）
- 宝塔面板已安装「Node.js 项目管理器」（软件商店搜索 Node）
- Nginx（宝塔自带）

## 部署步骤（首次）

1. **上传解压**：把 `baota-package.zip` 上传到站点目录（例如 `/www/wwwroot/short-url/`）并解压。
2. **安装依赖**：
   ```bash
   cd /www/wwwroot/short-url/backend
   npm install --omit=dev
   ```
3. **配置环境变量**：
   ```bash
   cd /www/wwwroot/short-url/backend
   cp ../.env.example .env
   # 编辑 .env：至少修改 ADMIN_PASSWORD（或设置 ADMIN_PASSWORD_HASH）
   ```
4. **启动 Node 服务**（二选一）：
   - **宝塔 Node 项目管理器**：添加项目 → 项目目录选 `backend`，启动命令 `node src/server.js`，
     端口 `3001`，运行用户 `www`，开机自启；
   - **命令行**（临时验证）：
     ```bash
     cd /www/wwwroot/short-url/backend && node src/server.js
     ```
   数据目录需要可写：
   ```bash
   chown -R www:www /www/wwwroot/short-url/backend/storage
   chmod -R 775 /www/wwwroot/short-url/backend/storage
   ```
5. **Nginx 反向代理**：网站 → 设置 → 伪静态 → 粘贴 `nginx-rewrite.conf` 全部内容 → 保存。
   网站根目录指向包内 `public/`（前端产物）。

浏览器打开站点即可使用；接口与旧版完全一致（`POST /url`、`/api/*`、`GET /admin`、`GET /{code}`）。

**验证 / 排障**：

- 直连 `http://127.0.0.1:3001/healthz` 应返回 `{"ok":true,...}`：说明 Node 已启动；
- 通过域名访问 `/healthz` 失败但直连成功 = 伪静态未生效或端口不一致；
- 无法访问首页 = 网站根目录未指向 `public/`。

## 更新部署

1. 上传新包解压覆盖（**不要覆盖 `backend/storage/`**，那是数据库所在目录）；
2. 若依赖有变化，重新执行 `npm install --omit=dev`；
3. 在 Node 项目管理器中重启项目。

SQLite 数据库在 `backend/storage/short-url.sqlite3`，**备份 = 拷贝这一个文件**。
包内不含数据库，覆盖解压不会影响线上数据。

## 目录说明

```text
public/                 前端构建产物（网站运行目录指向这里）
backend/
├── src/                Node 后端源码（HTTP / 服务 / 仓储 / 缓存）
├── tools/              手动巡检工具（正式巡检已内置在进程内）
├── package.json        依赖清单（生产依赖只有 bcryptjs）
├── package-lock.json
└── storage/            数据目录：SQLite 数据库与日志（首次启动自动创建）
.env.example            环境变量模板（复制为 backend/.env 使用）
nginx-rewrite.conf      Nginx 伪静态内容
部署说明.md             本文件
```

## 注意事项

- **必须部署在域名根目录**，不支持子目录（短码路由位于根路径）；
- 外链巡检：默认每 3600 秒在进程内自动执行一轮，同一条短链 24 小时内不重复检测；
  如需关闭或调整，修改 `.env` 的 `HEALTH_SCAN_ENABLED` / `HEALTH_SCAN_INTERVAL_SECONDS`；
- 缓存：默认使用本机 Memcached（`MEMCACHED_SERVERS=127.0.0.1:11211`）；
  未安装时自动降级为直连数据库，短链功能不受影响；
- 修改 `.env` 后需要重启 Node 项目才能生效（管理后台里的设置项除外，那些实时生效）。

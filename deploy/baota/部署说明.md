# 宝塔部署说明（开箱即用 · 标准 PHP 项目结构）

本包是完整部署包：编译好的前端 + 后端 + SQLite，全部自包含，无需 Node、无需 Composer、无需 Redis。
遵循标准 PHP 结构：`public/` 是唯一的 Web 运行目录，应用代码、配置、依赖、数据都在 Web 根之外。

## 部署步骤（首次）

1. **上传 zip**：把主项目根目录的 `baota-package.zip` 上传到宝塔站点目录，
   例如 `/www/wwwroot/short-url/`（宝塔 → 文件 → 上传 → 右键解压）。
2. **运行目录**：网站 → 设置 → 网站目录 → 运行目录选择 **`/public`** → 保存。
3. **PHP 版本**：网站 → 设置 → PHP 版本选 **8.2+**，并确认已启用 `pdo_sqlite` 扩展
   （宝塔官方包一般默认内置，phpinfo 搜索 `pdo_sqlite` 可确认）。
4. **访问**：
   - **Nginx**：网站 → 设置 → 伪静态 → 把 `nginx-rewrite.conf` 的内容整段粘贴进去 → 保存（仅此一步）；
   - **Apache**：无需任何配置（`public/.htaccess` 已内置生效）。

浏览器打开站点即可使用；接口 `POST /url`、`POST /api/url`、短码跳转 `GET /{code}` 与主项目完全一致。

**验证 / 排障**：访问 `http://你的域名/check.php`（环境自检页）。
自检页会逐项检查 PHP 版本、pdo_sqlite、storage 可写、数据库连接，并实测"创建接口 + 短码路由"
是否被伪静态正确转发（探针短链用完即清理，不残留数据）。
页面能打开但路由实测失败 = 伪静态未生效；本页也无法打开 = 站点未启用 PHP 或运行目录未指向 public。
**排障完成后请删除 `public/check.php`。**

## 更新部署（上传单个 zip 文件）

主项目每次重新打包都会产出**单文件发布包** `baota-package.zip`，上传到站点目录解压覆盖即完成更新。

- **zip 内不含数据库**（`storage/` 整个目录都不在包里），覆盖解压**永远不会影响服务器上的短链数据**；
- 数据库由程序在首次访问时自动创建（含全部表结构），服务器上已有数据库则继续使用，两者都不需要你操作；
- 唯一要注意的是 `.env`：zip 内包含它，覆盖会替换服务器上已改过的配置（如管理员密码）。
  更新时请在宝塔解压对话框里**跳过 `.env`**，或解压前把服务器上的 `.env` 备份一下再恢复；
  服务器尚未配置过 `.env`（首次部署）则无需处理。

## 目录说明

```text
public/               Web 运行目录（宝塔"运行目录"指向这里，唯一对外暴露的目录）
├── index.php         前端控制器：短码跳转与创建接口（静态资源由 Web 服务器直出，内置服务器兜底）
├── check.php         环境自检页（排障用，完成后请删除）
├── .htaccess         Apache 伪静态（自动生效）
├── index.html        编译好的前端首页（Vite 产物）
├── assets/ favicon.svg favicon.ico logo100.png manifest.json robots.txt   前端静态文件
app/                  PHP 后端代码（Controller / Service / Repository / Cache）
config/               配置定义（唯一读取环境变量的地方）
routes/               路由注册
vendor/               Composer 依赖（--no-dev 精简）
storage/              运行目录（空的 logs/）：SQLite 数据库（storage/short-url.sqlite3）由程序首次访问时自动创建
.env / .env.example   环境变量，默认即生产配置（APP_DEBUG=false）
nginx-rewrite.conf    Nginx 伪静态粘贴内容
```

## 注意事项

- **必须部署在域名根目录**，不支持子目录（短码路由位于根路径）；
- SQLite 数据库在 `storage/`，PHP-FPM 运行用户（宝塔默认 www）需要可写：
  `chown -R www:www storage && chmod -R 775 storage`；
- **备份数据** = 拷贝 `storage/short-url.sqlite3` 一个文件；
- 更换存储位置：编辑 `.env` 的 `DATABASE_PATH`；
- 缓存：默认驱动为 Memcached，服务器未装扩展/服务时自动降级为直连数据库（短链功能不受影响）；
  装了 Memcached 后可在管理后台「设置」页启用；
- 管理后台默认账号 `admin` / 密码 `admin123`，上线后请及时修改（`.env` 里设 `ADMIN_PASSWORD_HASH`）；
- `app/`、`config/`、`vendor/`、`storage/`、`.env` 都在 Web 根之外，无法被外网直接访问；
- 前端/后端更新：在主项目重新打包，上传新的 `baota-package.zip` 按上述「更新部署」执行。

上线前必做与未验证项

如实标注未能验证的部分，不伪造结果。

上线前必做（3 项）

!使用 memcached 的部署务必包含本轮修复（SEC-N01）
docker-compose / 单容器 runtime 默认内置 memcached；CACHE_DRIVER=none 不受影响
!修改管理后台默认密码 admin123
推荐设置 ADMIN_PASSWORD_HASH，或登录后台「设置」页修改
!设置 IP_HASH_SECRET
如 openssl rand -hex 32；设置后 IP 改用 HMAC，数据库泄露也无法反推 IP
!确认 APP_DEBUG=false、APP_ENV=production
宝塔部署另需删除 public/check.php 与 .check-token
HTTPS 站点建议同时设置 APP_URL=https://你的域名 与 HSTS_MAX_AGE=31536000；跨域部署前端需把前端源写入 ALLOWED_ORIGINS。

未验证项（如实标注）

?Docker 镜像构建与容器内运行 未执行
本机无 Docker；compose / Dockerfile 为静态审阅（storage 预建并归属 node 用户、端口未发布、npm ci --omit=dev）
?Nginx / 真实 memcached 实测 未执行
注入以同协议 mock 等价验证，防护点在客户端拼接层；三份 Nginx 配置静态审阅（均强制 X-Real-IP）
?IPv6 真实链路 / NAT64 路由 未执行
本机无对应路由环境；以前缀判定单元测试覆盖（13 应拒 + 4 应放行）
?大规模压力测试 有意未做
按审计规则不做不可控压力测试；仅小规模并发验证正确性
真实数据库与 3001 端口未被触碰。 全部实测使用独立测试库与独立端口 3021/3022； 项目自身的 backend/storage/short-url.sqlite3 未被修改或删除。 另用其副本验证了旧库升级：新增表自动创建，15 行数据全部保留，无需手工迁移。

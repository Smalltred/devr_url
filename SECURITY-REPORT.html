07

明确判定为「非漏洞」的检查项

审计规则要求：不存在攻击面时明确写明 Not Applicable，不把理论风险当漏洞。

Not Applicable（无此攻击面）

⊘SSRF · 后端从不请求用户提交的 URL，仅 parse_url 校验后落库并 302
无预览、无标题抓取、无 URL 探测
⊘SQL 注入 · 全量 PDO::prepare + 绑定参数，LIKE 通配符显式转义
实测 ' OR 1=1 --、'; DROP TABLE --、UNION SELECT 均无效
⊘命令执行 / 任意文件写入 · 全项目无用户输入路径进入 exec/system/eval/include
⊘IDOR · 单管理员模型，所有管理接口作用于全站资源，无按用户划分的归属
⊘短链删除后数据残留 · 同一 BEGIN IMMEDIATE 事务内删除短链与全部点击记录
⊘容器逃逸类风险 · 无 privileged、无 host network/PID、未挂载 Docker Socket

设计取舍 / 已验证通过（非漏洞）

i顺序短码可枚举 · 与原 Node 版逐位兼容的既有产品行为
后台可开启随机短码（最短 3 位，random_int）。短码是公开分享的跳转标识，非访问控制凭据
i开放重定向 · 302 跳转是产品核心功能
已核实：仅接受 http/https；CRLF 不能注入 Location（实测仅有原始 location 头）
✓并发与碰撞 · 10 / 50 / 100 并发创建，无重复短码、无错误
计数器在 BEGIN IMMEDIATE 内自增，code 为主键
✓限流不可被代理头绕过 · 换 6 个不同 X-Forwarded-For 仍在第 6 次被 429
✓日志不含敏感值 · 检索 password/token/bearer/cookie/api_key 仅命中固定文案 "admin password changed"
✓存储型 XSS 不可行 · src/ 无 v-html/innerHTML/eval；用户数据全部经 Vue 文本插值转义
